# ลอยกระทงออนไลน์ (Loy Krathong Online)

เว็บไซต์ลอยกระทงออนไลน์ ให้ทุกคนสร้างกระทงของตัวเอง เลือกดอกไม้ เขียนคำอธิษฐาน แล้วปล่อยลงแม่น้ำร่วมกับกระทงของคนอื่นแบบเรียลไทม์ โดยไม่ต้องสมัครสมาชิก

พัฒนาด้วย **PHP 8.2+ · SQLite · HTML/CSS/JavaScript** (ไม่ใช้เฟรมเวิร์ก ไม่ต้องติดตั้ง package ใดเพิ่ม)

## ฟีเจอร์

**สำหรับผู้เข้าชม**

- **สร้างกระทง 5 ขั้นตอน**: ชื่อเล่น → เลือกกระทง (10 แบบ) → ชุดดอกไม้ (8 ชุด จาก 15 ชนิด) → คำอธิษฐาน (สำเร็จรูปหรือเขียนเอง) → ตรวจสอบ พร้อมตัวอย่างกระทงแบบเรียลไทม์
- **แม่น้ำของทุกคน**: ฉากแม่น้ำยามค่ำคืน กระทงลอยไปมาตามมุมมองใกล้–ไกล กระทงลอยซ้อน/ทับกันได้ มีเมฆ โคมลอย หิ่งห้อย และประกายบนผิวน้ำ กระทงใหม่ของคนอื่นลอยเข้ามาเองโดยไม่ต้องรีเฟรช
- **กระทงของฉัน**: จำกระทงล่าสุดของแต่ละเครื่องด้วย cookie แสดงชื่อและคำอธิษฐานตลอด
- **หน้าแชร์กระทง** (`view.php?id=…`): อนิเมชันปล่อยกระทงลงน้ำ, ปล่อยซ้ำได้, คัดลอกลิงก์แชร์, **บันทึกเป็นรูปภาพ** PNG 1080×1350 สำหรับโพสต์โซเชียล (วาดในเบราว์เซอร์ ไม่ใช้เซิร์ฟเวอร์) และมี og:image ให้พรีวิวสวยใน LINE/Facebook
- **แกลเลอรี**: ดูกระทงทั้งหมดเป็นรายการ แตะเพื่ออ่านคำอธิษฐาน
- **ระบบเสียง**: เพลงพื้นหลัง เสียงบรรยากาศ (สายน้ำ ลม จิ้งหรีด ระฆังวัด) และเสียงเอฟเฟกต์ ปรับระดับเสียงแยกกันได้ เริ่มต้นปิดเสียงและจำค่าไว้
- **รายงานกระทงที่ไม่เหมาะสม**: กดรายงานได้จากหน้าแม่น้ำ แกลเลอรี และหน้าแชร์
- รองรับมือถือ แท็บเล็ต และ `prefers-reduced-motion`

**สำหรับผู้ดูแล** (`/admin/`)

- แดชบอร์ด, รายการกระทงทั้งหมด, รายงานกระทง, บันทึกกิจกรรม, หน้าระบบ
- ซ่อน / แสดงอีกครั้ง / ลบถาวร, ตัวกรอง "มีรายงานรอตรวจ", เลือกหลายรายการพร้อมกัน
- ใช้งานบนมือถือได้ (เมนู drawer, ตารางเป็นการ์ด)

**ความปลอดภัยและการป้องกันสแปม**

- กรองคำหยาบไทย/อังกฤษ ทั้งฝั่งเบราว์เซอร์ (ระหว่างพิมพ์) และฝั่งเซิร์ฟเวอร์ (ตอนบันทึก)
- CSRF token, honeypot, rate limit ต่อ IP (เก็บเฉพาะ hash), ตรวจ `Origin` ของ API รายงาน
- ระบบ **ไม่ซ่อนกระทงอัตโนมัติ** ไม่ว่ามีรายงานกี่ครั้ง ผู้ดูแลเป็นผู้ตัดสินเสมอ

## เริ่มใช้งานในเครื่อง

ต้องมี **PHP 8.2 ขึ้นไป** และเปิด extension `pdo_sqlite`, `sqlite3`, `mbstring` ใน `php.ini`

```bash
php -m                      # ตรวจว่ามี extension ครบ
php -S localhost:8000       # รันเซิร์ฟเวอร์สำหรับพัฒนา
```

เปิด `http://localhost:8000` ระบบจะสร้าง `database/database.sqlite` พร้อมข้อมูลตั้งต้นให้เองเมื่อเปิดครั้งแรก

> `php -S` ไม่อ่าน `.htaccess` และไม่รองรับ HTTP Range (เพลงจะเล่นต่อตำแหน่งเดิมข้ามหน้าไม่ได้) ใช้เพื่อพัฒนาเท่านั้น

### ตั้งรหัสผู้ดูแล

```bash
php -r "echo password_hash('รหัสผ่านของคุณ', PASSWORD_DEFAULT), PHP_EOL;"
cp config/admin.sample.php config/admin.php   # แล้วใส่ hash ลงไป
```

หรือตั้ง environment variable `KRATHONG_ADMIN_HASH` แทน แล้วเปิด `/admin/` เพื่อเข้าสู่ระบบ ไฟล์ `config/admin.php` ถูก ignore โดย Git

## การตั้งค่า (Environment variables)

| ตัวแปร | ใช้ทำอะไร |
|---|---|
| `KRATHONG_DB_PATH` | ที่เก็บไฟล์ฐานข้อมูล (แนะนำให้อยู่นอก web root) ถ้าไม่ตั้งจะใช้ `database/database.sqlite` |
| `KRATHONG_ADMIN_HASH` | hash รหัสผ่านผู้ดูแล (ใช้แทน `config/admin.php` ได้) |
| `KRATHONG_BASE_URL` | โดเมนจริง เช่น `https://example.com` เพื่อให้ og:url / og:image ถูกต้อง |
| `KRATHONG_TRUST_PROXY` | ตั้งเป็น `1` เมื่ออยู่หลัง Cloudflare / reverse proxy เพื่อให้ rate limit ใช้ IP จริง (อย่าเปิดถ้าไม่ได้อยู่หลัง proxy) |

## นำขึ้นเซิร์ฟเวอร์

1. ย้ายไฟล์ฐานข้อมูลไปไว้**นอก web root** แล้วตั้ง `KRATHONG_DB_PATH` (โฟลเดอร์ต้องเขียนได้โดยผู้ใช้ที่รัน PHP)
2. **Apache**: มี `.htaccess` กัน `database/`, `config/`, `includes/`, `_src/` และไฟล์ `.sqlite`/`.sql`/`.md`/`.log` ให้แล้ว (ต้องเปิด `AllowOverride All`) รวมถึงตั้งแคชและบีบอัดข้อความ
3. **nginx**: เพิ่มใน server block
   ```nginx
   location ~ ^/(database|config|includes|_src)/ { deny all; }
   location ~* \.(sqlite|sqlite-wal|sqlite-shm|sql|md)$ { deny all; }
   location /assets/ { expires 30d; }
   ```
4. ทดสอบเปิด `/database/database.sqlite` และ `/config/database.php` ในเบราว์เซอร์ ต้องได้ 403/404
5. ถ้าอยู่หลัง CDN **อย่า cache HTML ของ `pages/river.php`** (ส่ง `Cache-Control: private, no-store` เพราะมีข้อมูลเฉพาะผู้ใช้)

### เช็กลิสต์ก่อนวันงานจริง

- [ ] ฐานข้อมูลอยู่นอก web root และเขียนได้
- [ ] ตั้ง `KRATHONG_TRUST_PROXY` / `KRATHONG_BASE_URL` ถูกต้อง
- [ ] `config/admin.php` เป็นรหัสผ่านของจริง ไม่ใช่ค่าตัวอย่าง และไม่อยู่ใน Git
- [ ] ไม่มี PHP error ในล็อก
- [ ] ลองแชร์ลิงก์หน้าแรกและ `view.php?id=…` ใน LINE/Facebook ดูพรีวิว
- [ ] ทดสอบหน้าแม่น้ำบนมือถือรุ่นเก่า
- [ ] วันงานมีคนเข้า `admin/` ตรวจรายงานเป็นระยะ

## ฐานข้อมูล

SQLite โหมด WAL (จึงอาจเห็นไฟล์ `*.sqlite-wal` / `*.sqlite-shm` ข้างไฟล์ฐานข้อมูล เป็นเรื่องปกติ) ตารางหลัก: `krathong_types`, `flowers`, `flower_sets`, `flower_set_items`, `krathongs`, `krathong_flowers`, `krathong_reports`, `rate_events`, `admin_log` (บันทึกกิจกรรมของผู้ดูแล)

การสร้างตาราง / ย้ายข้อมูล / seed จะรัน **เฉพาะเมื่อ `PRAGMA user_version` ต่ำกว่า `DB_SCHEMA_VERSION`** (ปัจจุบันคือ **5** ใน `config/database.php`) ไม่ใช่ทุก request ดังนั้น**ถ้าแก้ `schema.sql` หรือ `seed.sql` ต้องเพิ่มเลข `DB_SCHEMA_VERSION` ด้วย** ฐานข้อมูลรุ่นเก่าจะถูกอัปเกรดเองเมื่อเปิดเว็บ

> ไฟล์ `database/database.sqlite` ถูก ignore โดย Git ไม่ควร commit ขึ้น Repository

ทดสอบเขียนพร้อมกัน 20 โปรเซส × 25 ครั้ง (รวม 500 กระทง) สำเร็จครบ ไม่มี "database is locked" ภายในราว 0.5 วินาที เกินความต้องการของเว็บนี้มาก

## การปรับแต่ง

**ชุดดอกไม้**: แก้ที่ `database/seed.sql` (`flower_sets`, `flower_set_items`) แต่ละชุดต้องรวมกันได้ **5 ดอกพอดี** ไม่เช่นนั้นจะไม่แสดง แล้วเพิ่ม `DB_SCHEMA_VERSION`

**ตัวกรองคำหยาบ**: แก้ที่ `profanityWordLists()` ใน `includes/profanity.php`

| รายการ | วิธีตรวจ |
|---|---|
| `loose` | ค้นหาทุกตำแหน่ง ตัดวรรณยุกต์ก่อนเทียบ |
| `strict` | ค้นหาทุกตำแหน่ง คงวรรณยุกต์ (กันเข้าใจผิด เช่น เหี่ยว/เหี้ย) |
| `token` | ต้องเป็นคำเดี่ยว ๆ (กันเช่น ห่าง/ห่า) |
| `compact` | ตัดช่องว่าง/สัญลักษณ์ก่อนค้นหา จับ `f u-ck` ใช้กับคำอังกฤษเท่านั้น |
| `allow` | คำปกติที่มีคำหยาบอยู่ข้างใน (เช่น เหี้ยม, แม่งาน) ตัดทิ้งก่อนตรวจ |

ตัวกรองจับการหลบเลี่ยง เช่น พิมพ์วรรณยุกต์ก่อนสระ, ไม้ยมกแทรกกลางคำ, ตัวอักษรซีริลลิก/กรีกที่หน้าเหมือนละติน และตัวเลขแทนตัวอักษร

**เหตุผลการรายงาน**: แก้ `REPORT_REASONS` ใน `includes/reports.php`

**โควตา rate limit**
- สร้างกระทง: 8 ครั้ง / 10 นาที และ 30 ครั้ง / วัน ต่อ IP (`pages/create.php`)
- รายงานกระทง: 5 ครั้ง / 10 นาที และ 20 ครั้ง / วัน ต่อ IP (`pages/report.php`)
- `check_text.php`: 90 ครั้ง / นาที · ล็อกอินแอดมินผิด: 5 ครั้ง / 10 นาที

**เปลี่ยนเพลง**: แทนที่ `assets/audio/background-music.mp3` (ถ้าดังหรือเบากว่าเดิม ปรับตัวคูณ `* 0.5` ใน `applyVolumes()` ของ `audio.js`) เสียงบรรยากาศและเอฟเฟกต์สังเคราะห์ด้วย Web Audio API ปรับได้ที่ `buildAmbience()` / `startAmbienceLoops()` เรียกเสียงเองได้ด้วย `KrathongAudio.play('splash')`

**เปลี่ยนภาพพื้นหลังแม่น้ำ**: ภาพที่ใช้คือ `assets/images/backgrounds/river-lantern-night.webp` (อ้างใน `style.css`, `index.php`, `pages/create.php`, `includes/functions.php` และใช้เป็นพื้นหลังของรูปที่บันทึกใน `view.js`) ถ้าเปลี่ยนภาพ ต้องแก้ตำแหน่งที่ผูกกับภาพ:
- `riverPolygon()` ใน `includes/functions.php` = พื้นที่น้ำ (% ของภาพ) ใช้กำหนดที่ลอยของกระทง, `clip-path` ของชั้นน้ำ และประกายบนผิวน้ำ พร้อม `RIVER_Y_FAR` / `RIVER_Y_NEAR`
- `riverCloudPolygon()` = พื้นที่ท้องฟ้าที่เมฆลอยได้
- `$skyGlows`, `$shoreGlows` (`pages/river.php`), `.fx-moon` / `.fx-lamp-*` (`style.css`), `MOON`, `launchZones` (`river.js`) = แสงจันทร์ โคม วัด

**จำนวนกระทงในแม่น้ำ**: `RIVER_MAX` ใน `pages/river.php` (ปัจจุบัน 40 ใบของคนอื่น) และ `MAX_BOATS` ใน `river.js` (30 ใบ เครื่องสเปกต่ำ 16) เกินแล้วกระทงเก่าสุดจะออกจากหน้าจอ (ไม่ถูกลบจากฐานข้อมูล)

## วิธีการทำงานที่ควรรู้

- **กระทงของผู้ใช้**: เบราว์เซอร์ถือ token สุ่ม 256 บิตใน cookie `kt_owner` (HttpOnly, SameSite=Lax, 1 ปี) ฐานข้อมูลเก็บเฉพาะ SHA-256 ของ token ไม่มีระบบกู้คืน ล้าง cookie หรือเปลี่ยนเครื่องจะไม่เห็นว่าอันไหนเป็นของตน
- **อัปเดตสด**: `pages/live.php` (อ่านอย่างเดียว ไม่เริ่มเซสชัน) ถูกเรียกทุก ~22–30 วินาที หยุดเมื่อซ่อนแท็บและอัปเดตทันทีเมื่อกลับมา ยอด "วันนี้" นับตามเวลาไทย (Asia/Bangkok) และไม่นับกระทงที่ซ่อน
- **ความเป็นส่วนตัว**: เก็บเฉพาะ hash ของ IP (ลบของเก่าเกิน 1 วัน) ผู้รายงานไม่ถูกเปิดเผยต่อเจ้าของกระทง และ IP เดิมรายงานกระทงใบเดิมซ้ำไม่ได้
- **การดำเนินการต่อรายงาน**: *ซ่อนกระทง* (หายจากแม่น้ำ/แกลเลอรี/หน้าแชร์ แต่ข้อมูลยังอยู่) · *ปัดตก* (กระทงแสดงตามเดิม) · *ลบถาวร* (ลบกระทงและรายงานทั้งหมด) ทุกการกระทำถูกบันทึกในบันทึกกิจกรรม

## ประสิทธิภาพ (ข้อควรรู้เวลาแก้โค้ด)

- กระทงในแม่น้ำเคลื่อนที่ด้วย **`transform` เท่านั้น** (`river.js` → `render()`) ห้ามแก้ `left/top` ซ้ำทุกเฟรม เพราะทำให้เบราว์เซอร์คำนวณเลย์เอาต์ใหม่ทั้งหน้า
- อนิเมชันให้ใช้ `transform`/`opacity` เท่านั้น และ**ไม่ใช้ `backdrop-filter` / `mix-blend-mode`** ทับฉากที่ขยับตลอด
- ใช้ลูป `requestAnimationFrame` เดียวทั้งหน้า หยุดเมื่อซ่อนแท็บหรือเปิดหน้าต่างคำอธิษฐาน
- มีตัวคุมเฟรมเรตอัตโนมัติ: ถ้าเฉลี่ยต่ำกว่า ~38 fps ต่อเนื่อง จะเพิ่ม class `is-lite` แล้ว `is-min` ที่ `#riverView` เพื่อตัดเอฟเฟกต์หนัก
- หิ่งห้อยลดเหลือ 12 ดวงบนมือถือ/เครื่อง CPU ≤ 4 คอร์ด
- CSS/JS ลิงก์ผ่าน `asset()` (ต่อ `?v=<เวลาแก้ไขไฟล์>`) จึง cache นานได้และเปลี่ยนเองเมื่อแก้ไฟล์
- `river-night.*` / `river-moon.*` ในโฟลเดอร์ `backgrounds/` เป็นภาพเก่าที่ไม่ได้ใช้แล้ว ลบทิ้งได้ ส่วน `.png` ของ `river-lantern-night` คือต้นฉบับของภาพปัจจุบัน
